##  Git: Решение конфликтов при Push

###  Ошибка: `Updates were rejected` (удаленный репозиторий ушел вперед)
Если на GitHub уже есть коммиты, которых нет у тебя локально, Git заблокирует пуш.

**Решение:**
1. Скачать и объединить истории:
   ```
     git pull origin main --allow-unrelated-histories



(Флаг --allow-unrelated-histories нужен, если ты создал новый локальный репозиторий и пытаешься слить его с существующим на GitHub)


      git push -u origin main


 Ошибка: Need to specify how to reconcile divergent branches
Git не знает, как объединять расходящиеся ветки.

Решение (настроить один раз):


      git config pull.rebase false


(Говорит Git, что при расхождении нужно делать обычный merge, а не rebase).

☢️Принудительная перезапись (ОСТОРОЖНО!)
Если ты хочешь полностью затереть историю на GitHub и залить свою локальную версию (например, ты накосячил с коммитами и хочешь начать с чистого листа).


       git push -u origin main --force


(Внимание: это удалит все коммиты на GitHub, которых нет у тебя локально. Использовать только в крайнем случае!).

 Проверка после слияния
Убедись, что всё прошло успешно:

Посмотреть историю коммитов:


         git log --oneline


Посмотреть какие файлы реально появились в папке 

          ls
