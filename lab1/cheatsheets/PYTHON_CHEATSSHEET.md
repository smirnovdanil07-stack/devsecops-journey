# 🐍 Шпаргалка по Python для DevSecOps

## Основы (модули)
- `import os` — работа с файловой системой и путями.
- `import sys` — работа с аргументами командной строки.
- `import subprocess` — запуск системных команд.

## Файлы и папки (os)
- `os.path.exists("path")` — проверить, существует ли путь (файл или папка).
- `os.path.isdir("path")` — проверить, является ли путь папкой.
- `os.makedirs("folder")` — создать папку (и все родительские).
- `os.path.join("folder", "file.txt")` — собрать путь (работает и в Windows, и в Linux).
- `open("file.txt", "w")` — открыть файл для записи (создаст или перезапишет).
- `open("file.txt", "r")` — открыть файл для чтения.

## Аргументы командной строки (sys)
- `sys.argv` — список аргументов. `sys.argv[0]` — имя скрипта, `sys.argv[1]` — первый аргумент.
- `sys.exit(1)` — выйти из скрипта с кодом ошибки (полезно для CI/CD).

## Запуск команд (subprocess)
- `subprocess.run(["ls", "-la"], capture_output=True, text=True)` — запустить команду и захватить вывод.

## Обработка ошибок (try/except)
- `try: ... except FileNotFoundError: ...` — ловить ошибки, чтобы скрипт не падал.
